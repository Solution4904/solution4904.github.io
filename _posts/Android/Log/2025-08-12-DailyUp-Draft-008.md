# 💡 3. 트러블슈팅 & 해결 방법
- 주간달력에서 날짜 클릭 시 하이라이트로 표시되는데 이전 주, 다음 주 버튼 클릭 시 하이라이트 위치가 그대로 표시되는 문제가 있었다. 단순하게 버튼 클릭 시 현재 날짜가 아니게되므로 위치를 없애는 방식으로 구현하려 했는데 이동했다가 다시 돌아왔을 경우에 문제가 생길 수도 있을 것 같아서 LocalDate에서 연 중에 오늘이 몇번 째 주인지 리턴해주는 함수가 있어서 이 데이터를 사용해 처리했다.
<br><br><br>

# 💡 4. 개선 사항
- MainActivity View에 너무 많은 View들이 존재함. Fragment 혹은 개별 View로 분리하고 Main에서 include하는 방식으로 사용하면 덜 복잡하게 만들 수 있을 것 같다.
- Calendar Adapter에서 사용되고 있는 데이터들의 최신화로 인한 UI 반영 작업들이 옵저버 방식으로 되어있으면 더 간결하고 일관성 있을 것 같다.
