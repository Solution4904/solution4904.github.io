# 💡 1. 진행한 작업
- 한 개로 만들어져있던 일정 아이콘 클릭 이벤트를 타입 별 아이콘 클릭 이벤트로 분리.
- 특정 날짜가 특정 기간 안에 포함되어 있는지 필터링하고 반환하는 데이터 로드 기능 추가.
- SharedPreference를 사용한 LocalDataManager를 어디에서든 사용할 수 있도록 object화.
- 특정 날짜가 속해있는 특정 기간의 처음 날짜와 마지막 날짜를 알아내는 기능 추가.

- xml에서 Resources로 접근한 이미지 데이터는 코드 상에서 Int와 다른 값이라고 한다.
- 특정 기간 안에 속하는 데이터를 필터링 하는 방법이 존재한다. 혹시나 특정 데이터로 가공해서 단순 구분 하는 방식으로 비교해서 데이터를 필터링 해야하나 싶었는데 날짜를 사용한 이전, 이후를 반환하는 함수가 이미 만들어져있다.
