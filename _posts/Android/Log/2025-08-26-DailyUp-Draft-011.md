# 💡 2. 알게 된 점
- ProgressBar의 process 값은 Int 타입이다. 아마 컴포넌트의 이름부터가 이런 데이터를 표시하는 용도 말고 로딩 중에 쓰이는 컴포넌트로서 만들어져서 굳이 실수형으로 들어가지 않나보다.
<br><br><br>
<!-- ---------- -->



# 💡 3. 트러블슈팅 & 해결 방법
- 체크 방식 일정의 경우 아이콘 클릭 시 완료 표시로 바뀌어 표현되어야 했는데 각 일정 별 아이콘은 코드에서 관리되고 있었고, 완료 표시로 사용할 아이콘은 xml에서 바로 접근시켰더니 아이콘 표현을 위해 만들어두었던 BindingAdapter가 작동하지 않는 문제가 발생했다. xml에서 Drawable을 접근했을 때와 코드에서 R.Drawable.~로 접근했을 때 Resource ID가 달라서 BindingAdapter로 만들어 둔 함수의 매개변수 값이 일치하지 않아서였다. Default 값으로 완료 아이콘을 넣어두면 편하긴 할텐데 너무 비효율적인 방법으로 생각되어서 아예 BindingAdapter 함수를 수정시켰다. 물론 이 방법도 결코 옳바른 방법처럼 보이진 않아서 나중에 개선이 필요해보인다.
